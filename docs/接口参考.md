# Web UI 与管理 API 参考

> 本文件是 `AGENTS.md` 第 4 节的**详细正文**，从 `AGENTS.md` 拆出以降低常驻上下文占用。
> 内容为**面板区块规划 + 管理 API（REST）全量清单**，随实现演进更新。

## 面板区块规划

Web UI 为**纯静态**（一个 `index.html` + `app.js` + `style.css`，`go:embed` 打进单文件，无前端编译链）。

| 页面/区块 | 内容 |
|-----------|------|
| 顶部栏 | 品牌名/版本号、API 地址（点击弹窗配置）、API-Key（点击弹窗修改）、帮助/关于 |
| 登录层 | 启用管理密码时先登录（HttpOnly cookie 会话）；设置弹层内置「退出登录」 |
| 账号管理 | **卡片（默认）/ 列表两种视图**（R157）：卡片 = 双列网格（升级前形态零改动）；列表 = **单表**按渠道分组（唯一列名表头 + 每渠道一个分组行：徽章 + 显示名 +「N 号」+ 小计），行含四列（账号 / 积分 / 状态 / 操作），**仅积分格与昵称可点**、整行不可点，虚拟账号行仍只读。汇总条上方是**功能按钮条**（刷新积分 / 全部签到 / 卡片⇄列表），顶部工具栏只剩渠道添加按钮。汇总条 chip 可点筛选（PR #68）、「不适用」虚拟账号默认收起（R103/R131）；**分组规则**：分组序沿用渠道顺序唯一规则（R142：内建按显示名字节序、自定义垫底），分组内保持后端下发原序；分组行小计与汇总条 chip 同源（同一 `channelSummaries` 的产物，逐字一致，token 计量/「不适用」分支同样透出）；分组行可点 = 筛该渠道（再点取消，chip 高亮同步）；过滤后一行不留的分组整段隐藏。窄屏列表横向滚动不裁剪列、不降级回卡片；视图偏好存 localStorage（`acct-view`，默认卡片，异常值回退） |
| 自动签到 | 签到时间（HH:MM 多组，点「＋」**就地展开时间选择器**手动选，确定才写盘）+ 开机自启开关（左右布局） |
| 用量与流水 | token 与积分流水（ledger 口径，R17）；token / 积分两个子 tab；token 表的模型榜带**缓存利用率**列（不变量 24）与**平均速度**列（stats 口径同源，R43）；区间选择（今日/7日）localStorage 记忆 |
| 费率 | **第四个主 tab**：各渠道模型定价表（按渠道分组），渠道标签带余额角标、模型名点击复制（PR #69） |
| 运行统计 | 实时统计（stats 口径，R43）：今日情况 / 平台概览 / 使用中接棒 / 最近临期 / 模型消耗 / 请求日志 / 异常账号 / 降级记录（R54，空态常显）/ 运行日志，30s 轮询 |

## 对外兼容端点（/v1/*，OpenAI 形状）

```
POST /v1/chat/completions        # 内层直接服务（不变量 12）
GET  /v1/models                  # 内层直接服务
POST /v1/responses               # gateway 兼容层（R13）
POST /v1/messages                # gateway 兼容层（Anthropic 形状）
POST /v1/messages/count_tokens   # gateway 兼容层
POST /v1/images/generations      # 文生图：**按请求的 model 名路由**到「会画图」的渠道
POST /v1/images/edits            # 参考图改图：同上
```

**images 路由与渠道差异（R158）**：`model` 必须是 `<渠道>/<上游ID>`（如 `glm/image`、
`modelscope/Qwen/Qwen-Image`、`modelscopeai/Qwen/Qwen-Image-Edit`）；无 `<kind>/` 前缀的裸名
（如 `gpt-image-1`）回落 `glm/image` 以兼容改造前客户端。未知渠道/渠道不实现生图 → **400
`invalid_model`**（不得 404，R139）。`size` 只收五档像素串或 `1:1/3:4/4:3/9:16/16:9`，其它值 400
（glm 上游对非法比例静默降级 1:1，本层必须拦截）；`n` 夹到 4；`response_format` 缺省/`b64_json`
→ 下载转 b64（单图下载失败**降级为 url**，不拖垮整批），`url` → 直传上游 URL 原串。

| 渠道 | 生图上游形态 | 参考图 |
|------|-------------|--------|
| `glm` | 同步（画图 agent 流式，一次 4 图，12~15s） | 单图硬约束 ⇒ 多图**客户端拼版 + 图床托管**；`output_format=png` 走 `image_process` 真转换 |
| `modelscope` / `modelscopeai` | **异步任务**（submit 拿 `task_id` → 请求内轮询，上限 `max(120s, timeout_seconds)`，超时 504 带 `task_id`） | 多张 `data:image/…` 或 http(s) 直链**原样直传**（不拼版不上图床）；总字节 >20MB → 400 |

生图按「账号级错误换号、请求级/任务级错误不换号」处置，**换号上限 = 池内账号数**（每号一次）；
限流（`ErrSoftRate`）先对该号做模型级冷却（key = 请求全串）再换，全池耗尽透传首因（429/502）。

## 渠道额度口径（ModelScope 魔粒，R161）

面板的「积分」列对两区显示**真实魔粒**（不是「不适用」）。端点全在**主站**（不在对话基址
`api-inference.*`），不在 `/v1/*` 下，也不经管理 API 暴露——由后端 `internal/modelscope` 直连：

| 用途 | 端点 | 鉴权 | 字段 |
|------|------|------|------|
| 余额 | `GET {site}/openapi/v1/magicubes/balance` | `Authorization: Bearer <ms- token>` | `data.{total_balance, available_balance, frozen_amount}` |
| 逐笔到期 | `GET {site}/openapi/v1/magicubes/transactions` | 同上 | `EARN.expire_at`（UTC+8 墙钟 `YYYY-MM-DD HH:MM:SS`）/ `EXPIRE` / `SPEND_CONFIRM` |
| 今日用量 | `GET {site}/api/v1/inference/rate-limit` | `Cookie: m_session_id=<ms- token>` | `Data.currentUsagePerDay`（按 token，`InfoOnly`，单位未实证） |
| 每日领取 | `GET {site}/api/v1/users/login/info` | 同上 | 幂等；三态借道 `transactions` 判（无独立签到端点） |

口径：可用 = `available_balance`（只含可消耗，参与选号与合计）；`frozen_amount` 进「不可用」小计
（`Usable=false`，不参与 `Pick()`）；`used` 负值夹 0（假设）。
**临期展示**：`transactions` 的逐笔 `EARN.expire_at`（UTC+8 墙钟）就是临期三境的唯一数据源——
「今日到期 / 明日到期 / 7 日内到期」按自然日分桶（`provider.ExpireBucketOf`，R105），窗口由
`config.schedule.expiring_days`（1/2/7，R112b）控制；选号不看临期体量，只看最早到期**时刻**
（`provider.EarliestExpire`，R112）。`transactions` 拿不到时临期列显示「—」（不编造）。
`credits_term="魔粒"` 只改**文案**，
`credits_unit` 保持空串 ⇒ **仍是积分**（进积分合计与折线，与 `credits_unit="token"` 的 ZCode 不同口径）。
失败口径：网络/5xx 保留旧快照并标「待刷新」（**不写 0**）；401/403 → `ErrSessionDead`（不 Disable、不冷却，
只能人工重贴 token）。

## 管理 API

均挂 `/api/*`；除 `/api/auth/*` 外均需有效面板会话——密码为空时不校验（R4）。

```
POST /api/auth/login               # {password} → {session}；下发 HttpOnly cookie
POST /api/auth/logout              # 注销当前会话
GET  /api/auth/state               # 会话探针（不返回 401）：全量状态 + auth_enabled/auth_session/auth_required
GET  /api/state                    # 全量状态（账号/积分/签到/配置）
POST /api/login/start              # {channel,account_label?} → {auth_url,backend_opened,manual_callback}
                                   # manual_callback=true ⇒ 该渠道回调写死回环（CodeArts / LobsterAI / TraeWork），前端显示「粘贴回调地址」兜底（R96/#98）
POST /api/login/callback           # {url} → {ok} 手动提交回环回调地址（CodeArts / LobsterAI / TraeWork；CodeArts 接受完整 URL / ?code=… / 裸 code，LobsterAI 与 TraeWork 接受完整 URL，均含端口自检）
POST /api/login/glm_auto           # 智谱清言自动登录：拉起独立 profile 浏览器（见 R27）
GET  /api/login/glm_auto_status    # → {status: idle|pending|success|failed|cancelled, uid?, nickname?, error?}

POST /api/login/lingxi_sid         # {sid} → {uid,warning} WPS 灵犀粘贴 wps_sid（整段 Cookie 头也可；与 comate 共用 Cookie 但 uid 前缀 lxsid-，见 R141）
POST /api/login/comate_sid         # {sid} → {uid,warning} WPS Comate 粘贴 wps_sid（整段 Cookie 头也可；见 R130/R131）
POST /api/login/comate_qr          # WPS Comate 扫码登录（服务端向 qr.wps.cn 申请二维码，NAS 可用；见 R132）

POST /api/login/comate_browser         # 接管 config.login.comate_browser_cdp 指向的已在跑浏览器（不关它）
GET  /api/login/comate_browser_status  # 同上状态形状
POST /api/login/comate_browser_cancel  # 只解引用，不关用户的浏览器
POST /api/login/modelscope_token    # {token} → {uid,warning} ModelScope（魔搭**国内站**）粘贴 `ms-` Access Token（R159）
  #   区域写死在路由上：kind=modelscope、上游 base=api-inference.modelscope.cn；App 侧仍有一道 kind 白名单

POST /api/login/modelscopeai_token  # {token} → {uid,warning} ModelScopeAI（魔搭**国际站**）粘贴同一形态 token（R159）
  #   kind=modelscopeai、上游 base=api-inference.modelscope.ai；落盘 `modelscopeai-<uid>.json`、uid 前缀 `msai-`

  #   硬拒：含 `/`、空白/逗号/`*`、与另一条规则重名、与 model_map 的键或渠道名重名、to 里写别名；
  #   与真实裸名重合只给软警告（允许保存）；成功响应带 {ok, warnings:[…]}

  #   `enabled` 字段已废弃（R83）；`models[].cap_source` = api/user/缺（R119：上游声明 / 手填 / 未探测）；

  #   后端按旧名回退找回真实密钥、级联改写 compat.model_map / default_channel / model_fallback / reasoning_efforts、旧 state 文件改名留 `.old`；返回 {ok, channels, renamed}
POST /api/config/custom_channel_test # {name,base_url,api_key} 端点定位 + 能力探测（R121/R122：规范化后有界嗅探候选根，封顶 3+3 个 GET，**绝不 POST**——POST 就是真实对话，会计费并落用户用量明细）
  #   返回 {ok, models:[裸 id], caps:[{id,display_name,context_window,max_tokens,supports_images,supports_reasoning,supports_tools,reasoning_efforts,default_reasoning_effort,cap_source}],
  #         base_url(定位后的真实根), adjusted, renormed, models_ok, chat_ok, tries:[{url,status,err}], note}；失败也回 HTTP 200 + ok:false + tries 逐条
POST /api/config/custom_channel_key # {name} 按需取单个渠道的 api-key 明文（R119/R122：面板点「复制」或点「眼睛」才调）
  #   /api/state 与 /api/fees 是 30s 轮询，**绝不**随它们批量下发明文；未命中回 404；日志只记渠道名，不记密钥
POST /api/config/proxy             # {proxy, oczen_api_key} 全局备用上游通道（R57：默认不参与任何请求，仅命中地区拒绝时自动重放）
POST /api/config/oczen_test        # {api_key} OpenCodeZen 凭证连通性测试
GET  /api/fees                     # 渠道费率（本地缓存 + 按需刷新）
POST /api/fees/refresh             # 异步刷新费率
GET  /api/usage                    # 用量/积分流水聚合（R17，ledger 口径；token 段含 cr/cr_cov/cr_reqs，不变量 24）
GET  /api/stats                    # 运行统计快照（R43，stats 口径）

GET  /api/logs                     # 最近 300 行日志
POST /api/quit                     # 退出程序
```

## 客户端端点（`/v1/*`，不是管理 API）

```
POST /v1/chat/completions          # OpenAI Chat 兼容；模型名 = `channel/<上游模型名>`，按前缀路由到渠道
GET  /v1/models                    # 静态表 ∪ 动态目录（R42）；能力只声明上游真实有的（R49/R124）；
  #   能出图的模型带 `supports_image_generation: true`（D12：与「能看图」的 architecture.input_modalities 正交）
POST /v1/responses                 # Responses API（兼容层，R13）
POST /v1/messages                  # Anthropic Messages（兼容层，R13）
POST /v1/messages/count_tokens     # 同上
POST /v1/images/generations        # 生图：**多 provider + 按模型名路由**（票 03/R158）
POST /v1/images/edits              # 图生图（同上）
  #   模型名即粘性路由与模型级冷却的 key：`glm/image`（原 glm 同步生图，行为零变化）
  #   以后 `modelscope/Qwen/Qwen-Image`（含 `/`，上游真模型名原样保留，只剥渠道前缀）
  #   路由判据 = 渠道是否实现 provider.ImageGenerator（可选接口）；未实现的渠道回 400 而非 500
```

> ModelScope 两区（R159）：对话 `/v1/chat/completions` + 目录 `GET /v1/models`（静态表 ∪ 上游目录，
> 上游名带斜杠如 `Qwen/Qwen-Image`，对外 ID 为 `modelscope/Qwen/Qwen-Image`）；生图是**异步任务**
> （submit + `X-ModelScope-Async-Mode` → `task_id` → 轮询 `GET /v1/tasks/{id}`），
> 对外仍是同步 OpenAI 形状。额度 = **真实魔粒**（主站 `/openapi/v1/magicubes/*` + 幂等每日领取）——
> R159 的「额度不适用」已由 **R161** 更正。
