# Web UI 与管理 API 参考

> 本文件是 `AGENTS.md` 第 4 节的**详细正文**，从 `AGENTS.md` 拆出以降低常驻上下文占用。
> 内容为**面板区块规划 + 管理 API（REST）全量清单**，随实现演进更新。

## 面板区块规划

Web UI 为**纯静态**（一个 `index.html` + `app.js` + `style.css`，`go:embed` 打进单文件，无前端编译链）。

| 页面/区块 | 内容 |
|-----------|------|
| 顶部栏 | 品牌名/版本号、API 地址（点击弹窗配置）、API-Key（点击弹窗修改）、帮助/关于 |
| 登录层 | 启用管理密码时先登录（HttpOnly cookie 会话）；设置弹层内置「退出登录」 |
| 账号管理 | 双列卡片网格，账号名/UID/积分/签到状态，图标按钮操作（签到/刷新/停用/删除）；顶部积分汇总条 chip 可点击筛选（PR #68） |
| 自动签到 | 签到时间（HH:MM 多组，点「＋」**就地展开时间选择器**手动选，确定才写盘）+ 开机自启开关（左右布局） |
| 用量与流水 | token 与积分流水（ledger 口径，R17）；token / 积分两个子 tab；token 表的模型榜带**缓存利用率**列（不变量 24）与**平均速度**列（stats 口径同源，R43）；区间选择（今日/7日）localStorage 记忆 |
| 费率 | **第四个主 tab**：各渠道模型定价表（按渠道分组），渠道标签带余额角标、模型名点击复制（PR #69） |
| 运行统计 | 实时统计（stats 口径，R43）：今日情况 / 平台概览 / 使用中接棒 / 最近临期 / 模型消耗 / 请求日志 / 异常账号 / 降级记录（R54，空态常显）/ 运行日志，30s 轮询 |

## 管理 API

均挂 `/api/*`；除 `/api/auth/*` 外均需有效面板会话——密码为空时不校验（R4）。

```
POST /api/auth/login               # {password} → {session}；下发 HttpOnly cookie
POST /api/auth/logout              # 注销当前会话
GET  /api/auth/state               # 会话探针（不返回 401）：全量状态 + auth_enabled/auth_session/auth_required
GET  /api/state                    # 全量状态（账号/积分/签到/配置）
POST /api/login/start              # {channel,account_label?} → {auth_url,backend_opened,manual_callback}
                                   # manual_callback=true ⇒ 该渠道回调写死回环（CodeArts / LobsterAI / TraeWork），前端显示「粘贴回调地址」兜底（R96/#98）
POST /api/login/callback           # {url} → {ok} 手动提交回环回调地址（CodeArts / LobsterAI / TraeWork；CodeArts 接受完整 URL / ?code=… / 裸 code，LobsterAI 与 TraeWork 接受完整 URL，均含端口自检）
POST /api/login/glm_auto           # 智谱清言自动登录：拉起独立 profile 浏览器（见 R27）
GET  /api/login/glm_auto_status    # → {status: idle|pending|success|failed|cancelled, uid?, nickname?, error?}
POST /api/login/glm_auto_cancel    # 取消自动登录并关闭浏览器
POST /api/login/glm_token          # {refresh_token} → {uid} 智谱清言手工兜底（见 R22）
POST /api/login/cline_key          # {api_key} → {uid,warning} Cline 粘贴官方 sk_ Key（见 R46；只调 /api-keys 验证，零 token 消耗；warning=同账号告警）
POST /api/login/lingxi_sid         # {sid} → {uid,warning} WPS 灵犀粘贴 wps_sid（整段 Cookie 头也可；与 comate 共用 Cookie 但 uid 前缀 lxsid-，见 R141）
POST /api/login/comate_sid         # {sid} → {uid,warning} WPS Comate 粘贴 wps_sid（整段 Cookie 头也可；见 R130/R131）
POST /api/login/comate_qr          # WPS Comate 扫码登录（服务端向 qr.wps.cn 申请二维码，NAS 可用；见 R132）
GET  /api/login/comate_qr_status   # → {state: idle|pending|scanned|success|failed|cancelled, qr?, uid?, error?}
POST /api/login/comate_qr_cancel   # 取消扫码登录
GET  /api/login/comate_browser_info    # → {configured, available, endpoint, hint?} 本机浏览器接管可用性
POST /api/login/comate_browser         # 接管 config.login.comate_browser_cdp 指向的已在跑浏览器（不关它）
GET  /api/login/comate_browser_status  # 同上状态形状
POST /api/login/comate_browser_cancel  # 只解引用，不关用户的浏览器
POST /api/login/cancel
POST /api/account/checkin          # {uid}
POST /api/account/checkin_all
POST /api/account/refresh          # {uid}
POST /api/account/refresh_all
POST /api/account/remove           # {uid}
POST /api/account/disable          # {uid,disabled} 停用/启用
POST /api/account/resource_detail  # {uid} → 积分明细
POST /api/account/nickname         # {uid,nickname} 修改显示名
POST /api/config/checkin_times     # {times:["09:00","21:30"]}
POST /api/config/expiring_days     # {days:1|2|7} 「积分汇总·临期」的展示口径（R112b：1=今日到期、2=今日+明日、7=7日内到期，
  #   与运行统计三桶同源；保存后立即刷一轮积分让面板当场生效；**不参与选号**——选号判据只有 provider.EarliestExpire）；
  #   非法值回 400，值未变直接返回（不写盘不刷上游）；当前值随 /api/state 的 `expiring_days` 下发
POST /api/config/listen            # {host,port,admin_password?}（非环回时必须带密码）
POST /api/config/admin_password    # {password}（空 = 关闭面板鉴权，仅环回监听允许）
POST /api/config/api_key           # {key}
POST /api/config/autostart         # {on:bool}
POST /api/config/compat            # 模型路由（默认渠道 / 封顶 tokens / 映射表）
POST /api/config/model_fallback    # {rules:[{from,to:[],name?}…]} 模型降级链（R54，保存即热生效）
  #   `name` = 链别名（R129，可选，空=无别名）：客户端请求它等同于请求 from，优先级 别名 > model_map > default_channel；
  #   硬拒：含 `/`、空白/逗号/`*`、与另一条规则重名、与 model_map 的键或渠道名重名、to 里写别名；
  #   与真实裸名重合只给软警告（允许保存）；成功响应带 {ok, warnings:[…]}
POST /api/config/reasoning_efforts # {efforts:{"channel/model":"high","*":"medium"}} 思考强度注入映射（R63，保存即热生效）
POST /api/config/custom_channels   # {channels:[{name,base_url,api_key,models}], renames:[{new,old}]} 自定义 OpenAI 兼容渠道（R66，保存即热生效；api_key 提交脱敏值 = 不修改）
  #   `enabled` 字段已废弃（R83）；`models[].cap_source` = api/user/缺（R119：上游声明 / 手填 / 未探测）；
  #   base_url 一律过 NormalizeBaseURL（R121/R122：补协议、丢 query+fragment+userinfo、循环剥 `/chat/completions`|`/completions`|`/models` 尾巴，中间前缀段不猜删）；
  #   `renames` 必须显式传：渠道标识就是 provider.Kind（state 文件、虚拟账号 UID、模型前缀都拼它），只比新旧两张表无法区分「改名」与「删一个+新增一个」（R122）；
  #   后端按旧名回退找回真实密钥、级联改写 compat.model_map / default_channel / model_fallback / reasoning_efforts、旧 state 文件改名留 `.old`；返回 {ok, channels, renamed}
POST /api/config/custom_channel_test # {name,base_url,api_key} 端点定位 + 能力探测（R121/R122：规范化后有界嗅探候选根，封顶 3+3 个 GET，**绝不 POST**——POST 就是真实对话，会计费并落用户用量明细）
  #   返回 {ok, models:[裸 id], caps:[{id,display_name,context_window,max_tokens,supports_images,supports_reasoning,supports_tools,reasoning_efforts,default_reasoning_effort,cap_source}],
  #         base_url(定位后的真实根), adjusted, renormed, models_ok, chat_ok, tries:[{url,status,err}], note}；失败也回 HTTP 200 + ok:false + tries 逐条
POST /api/config/custom_channel_key # {name} 按需取单个渠道的 api-key 明文（R119/R122：面板点「复制」或点「眼睛」才调）
  #   /api/state 与 /api/fees 是 30s 轮询，**绝不**随它们批量下发明文；未命中回 404；日志只记渠道名，不记密钥
POST /api/config/proxy             # {proxy, oczen_api_key} 全局备用上游通道（R57：默认不参与任何请求，仅命中地区拒绝时自动重放）
POST /api/config/oczen_test        # {api_key} OpenCodeZen 凭证连通性测试
GET  /api/fees                     # 渠道费率（本地缓存 + 按需刷新）
POST /api/fees/refresh             # 异步刷新费率
GET  /api/usage                    # 用量/积分流水聚合（R17，ledger 口径；token 段含 cr/cr_cov/cr_reqs，不变量 24）
GET  /api/stats                    # 运行统计快照（R43，stats 口径）
GET  /api/stats/logs?limit=15      # 运行统计的最近请求日志行
GET  /api/logs                     # 最近 300 行日志
POST /api/quit                     # 退出程序
```
