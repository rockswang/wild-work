本页是自包含静态演示件（假数据 / 无后端 / 无网络请求 / 无 JS），仅用于确认版式，不是实现分支。
请确认：
  1. 五列字面序：平台 / 账号 / 积分 / 状态 / 操作，全表只有最顶部一行列名表头。
  2. 每个渠道块内只有「分组行 → 数据行」，没有列名行（列名只出现一次）。
  3. 平台列 = 渠道徽标 + 渠道显示名；紧凑档（≤869px）只留徽标（勾选下方开关即可模拟紧凑档）。
  4. 账号列 = 昵称（可点改名）+ 第二行 UID: <短 uid>。
⚠️ 请重点看一处：「平台徽标」内文字本身就是渠道显示名，而规格要求平台格「含徽标 + 显示名」， 故宽屏下徽标右侧另有一份显示名文字（紧凑档隐藏）。若嫌重复，请在确认时指出期望形态 （如：徽标只留色块 / 宽窄档都只留徽标 / 保留现状）。此处不自行改方案。
—— 点击切换（按钮高亮 = 已开启）；关闭为宽屏档（平台列「徽标 + 显示名」）；也可直接缩放窗口，≤869px 自动进入紧凑档。
