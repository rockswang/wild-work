配置说明

1. 添加账号后自动完成登录（Qoder 渠道当前无签到活动，仅 API 转发）。

2. AI 客户端配置：Base URL http://127.0.0.1:7863/v1，API Key 见页面顶部。

3. 模型 ID 需带渠道前缀：workbuddy/<model>、traework/<model>、qoder/<model>。

4. 积分会随聊天消耗实时变化，"全部刷新积分"可即时获取最新余额。

5. 日志文件位于 exe 目录下 data/app.log，可从托盘菜单"查看日志"打开。

6. 退出程序：右键托盘图标选择"退出"。

7. 本工具仅供个人学习使用，请遵守各上游平台服务条款。
