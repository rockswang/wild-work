自动登录
  1. 已为你打开一个**独立的浏览器窗口**（不影响你日常浏览器的登录态）。

  3. 登录完成后**无需任何操作**，这里会自动捕获凭据并添加账号。

添加 Cline 账号
申请办法
  1. 打开 app.cline.bot 并注册账号。
  2. 进入 Account / API Keys → Create API Key。
  3. Key（形如 sk_ + 64 位十六进制）只在创建时完整显示一次，请立即复制粘贴到下面。
⚠️ 必须使用多个独立账号各自的 Key
  1. 官方免费额度按 Cline 账号计（其权益字段名为 …UsageCostUSDPerUser）。
  2. 同一个账号下创建多把 Key 共享同一份额度，不会增加可用额度。 本工具在检测到多把 Key 同属一个账号时会给出提示。
  3. 想扩额度请注册多个独立 Cline 账号，每个账号各建一把 Key，逐个粘贴添加。

备用上游通道
全局只配一个备用代理（http/https/socks5），留空 = 无备用通道。 它不影响本工具的任何常规请求：所有渠道一律直连；只有上游回「地区限制」时， 才在同一次请求内自动改走备用通道重发一次（重发也失败则透传原始错误）。 目前取用方：Cline 与 OpenCodeZen（两渠道的部分模型直连会被上游按地域拒）。
OC Zen Key 留空 = 匿名凭证；填入 sk-… 自定义 key 可解锁独立配额与付费模型。 「测试」按钮与真实对话同源：直连被上游按地区拒绝时也会自动改走备用通道， 结果会标明答复来自直连还是备用出口——否则配了代理点测试仍看到 403，无从判断代理到底生效了没有。
模型降级链
主模型在渠道全部账号上限流冷却（503 提示解冻时间）时，按顺序找第一个可用的备胎模型顶上，响应头 X-Model-Fallback 标注实际备胎；原模型解冻后自动切回，不粘滞。模型 ID 用 channel/model 全路径（如 workbuddyai/deepseek-v4.1-flash），备胎可跨渠道。
思考强度
客户端请求未带 reasoning_effort 时，按请求模型 ID 注入配置的思考档位；客户端显式传了的（任意值）一律不覆盖；精确未命中回退全局默认。哑管道不校验档位取值（支持什么档位由渠道模型自己决定）；TraeWork 渠道协议无 reasoning 注入点，注入无害但无效。模型 ID 用 channel/model 全路径（如 workbuddyai/deepseek-v4.1-flash），* 为全局默认。
自定义渠道（OpenAI 兼容）
先配置渠道标识、地址与 API 密钥，再在各渠道下配置模型 ID、上下文大小、思考等级与多模态能力。客户端用 渠道标识/模型名 访问，用量与统计全线统一。渠道标识不得与内建渠道同名（如 workbuddy / cline / oczen / raccoon 等）。

配置说明

1. 添加账号后自动完成登录（WorkBuddy 国际版无需手动签到，定时自动领取日活奖励；Qoder 渠道无签到活动，仅 API 转发）。

2. AI 客户端配置：Base URL http://127.0.0.1:7863/v1，API Key 见页面顶部。

3. 支持三种接口协议：
· OpenAI Chat：POST /v1/chat/completions（旧版客户端）
· OpenAI Responses：POST /v1/responses（codex CLI）
· Anthropic Messages：POST /v1/messages（claude CLI，Base URL 不带 /v1）
Anthropic 客户端用 x-api-key 或 Authorization: Bearer 均可。

4. 模型 ID 建议带渠道前缀：workbuddy/<model>、workbuddyai/<model>、traework/<model>、qoder/<model>； 也支持裸名（走「设置 → 模型路由」的 默认渠道 / 映射表 配置）。

5. 账号显示名可点击卡片上的名字直接修改；顶栏齿轮进入统一设置（监听 / API-Key / 模型路由 / 备用上游通道）。

6. 备用上游通道：全局只配一个代理地址（http/https/socks5），不影响任何常规请求（所有渠道一律直连）； 仅当上游回「地区限制」时，本工具会在同一次请求内自动改走该通道重发一次。目前取用方：Cline 与 OpenCodeZen。

7. 积分会随聊天消耗实时变化，"全部刷新积分"可即时获取最新余额。

8. 日志文件位于 exe 目录下 data/app.log，可从托盘菜单"查看日志"打开。

9. 退出程序：右键托盘图标选择"退出"。
