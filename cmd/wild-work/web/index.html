配置说明

1. 添加账号后自动完成登录（WorkBuddy 国际版无需手动签到，定时自动领取日活奖励；Qoder 渠道无签到活动，仅 API 转发）。

2. AI 客户端配置：Base URL http://127.0.0.1:7863/v1，API Key 见页面顶部。

3. 支持三种接口协议：
· OpenAI Chat：POST /v1/chat/completions（旧版客户端）
· OpenAI Responses：POST /v1/responses（codex CLI）
· Anthropic Messages：POST /v1/messages（claude CLI，Base URL 不带 /v1）
Anthropic 客户端用 x-api-key 或 Authorization: Bearer 均可。

4. 客户端模型名必须带渠道前缀，否则网关无法判断该走哪个渠道（报 model "xxx" needs an explicit channel prefix）。当前已接入渠道的前缀 （点击可复制，完整模型名为 前缀 + 模型名）：

也支持裸名（走「设置 → 模型路由」的 默认渠道 / 映射表 配置）。

5. 账号显示名可点击卡片上的名字直接修改；顶栏齿轮进入统一设置（监听 / API-Key / 模型路由 / 备用上游通道）。

6. 备用上游通道：一个全局代理地址（http/https/socks5），留空即关闭。它不影响常规请求—— 所有渠道照常直连，只有上游按地区拒绝时（cline 区域限制模型、OpenCodeZen 的 RegionError） 才由该渠道在同一次请求内取用它重放一次。

7. 积分会随聊天消耗实时变化，"全部刷新积分"可即时获取最新余额。

8. 日志文件位于 exe 目录下 data/app.log，可从托盘菜单"查看日志"打开。

9. 退出程序：右键托盘图标选择"退出"。
